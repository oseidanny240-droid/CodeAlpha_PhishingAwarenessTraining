# CodeAlpha - Phishing Awareness Training Module

## Description
An interactive web-based cybersecurity awareness training module designed to educate users on identifying phishing emails, social engineering tactics, and suspicious links.

## Features
- **Interactive Knowledge Check**: Evaluates user decisions on real-world email scenarios.
- **Instant Feedback**: Displays explanations for legitimate vs. phishing indicators.
- **Dynamic Quiz Engine**: Cycles through scenario questions with score and state management.
- **Responsive UI**: Clean, modern interface styled for desktop and mobile browsers.

## Tech Stack
- **HTML5**: Structural markup for training content and quiz card.
- **CSS3**: Custom layout styling and interactive button hover states.
- **JavaScript (ES6)**: Dynamic scenario loading, user input evaluation, and state handling.

## How to Run
1. Clone or download this repository.
2. Open `index.html` directly in any web browser (Google Chrome, Microsoft Edge, Firefox).
3. Interact with the scenarios and click through the knowledge check questions.
